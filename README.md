Kaprekar's Constant (6174)

The Math: Take any 4-digit number as long as it is not all identical digits, like 1111. 
Arrange the digits in descending order, the ascending order, and subtract the smaller 
number from the larger one. 
If you repeat this process, you will always reach the number 6174 in 7 steps or fewer.

Challenge to write a Python function that takes a 4-digit number, loops through the 
subtraction steps and counts how many iterations is taken to hit 6174.

This one was one of those math problems that sounds harder than it really is. The code 
was easy enough and I ended up with two version. 

First version is simple enough, jsut take the number and use a while loop to to go 
through subtraction and count steps. 

Second attempt was just a simpler way to code it according to how my brain works through 
this problem. The formula at the end is the same outcome as subtraction step.
